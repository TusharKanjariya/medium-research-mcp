# Roadmap — medium-research-mcp

Each milestone is sized to one GSD phase (Plan → Execute → Verify) in its own
fresh context. Build order = simplest-and-highest-leverage first, validate the
pattern, then breadth, then the complex YouTube wrapper last. Acceptance for
every server: tools register; helpers unit-tested; output matches the contract
(ARCHITECTURE.md §4); keyless/required-cred behavior correct.

> **Repo status (2026-07-01):** This repository currently contains design docs
> only — no code has been committed yet (`servers/`, `shared/`, `package.json`
> are not present). Phases 0 and 1 below describe the intended foundation and
> are the first work to build, not completed work. The canonical execution
> roadmap is generated by GSD in `.planning/ROADMAP.md`.

## Phase 0 — Pattern validation
- Hacker News server (`hn_front_page`, `hn_search`, `hn_get_item`).
- Shared `cache.js` + `http_client.js`.
- Normalized output contract established and verified.

## Phase 1 — Credential + auth infrastructure
- `credentials.js` (env-only, single source of truth, graceful vs required).
- `auth.js` (Reddit password grant + Lemmy login, token caching).
- `.env.example`; `.mcpb` `user_config`/keychain pattern documented.

## Phase 2 — Stack Exchange
- Build the Stack Overflow server, then generalize to the whole network via a
  `site` param (serverfault, superuser, dba, security, softwareengineering, …).
- Tools: `so_hot_questions(tag, sort)`, `so_search(query, tag, site)`,
  `so_get_question(id)`.
- Auth: optional `STACKEXCHANGE_KEY` (300 → 10k/day). Highest breadth-per-effort.

## Phase 3 — Reddit replacement pair
- **Lobsters** (no auth): `lobsters_hottest`, `lobsters_tag(tag)`, `lobsters_get(id)`.
- **Lemmy** (public reads; auto-auth when `LEMMY_*` env present): `lemmy_hot`,
  `lemmy_search`, `lemmy_post(id)`. End-to-end test of the username/password path.

## Phase 4 — Competitive scoping
- **Dev.to** (no auth): trending by tag, search (client-side filter), article.

## Phase 5 — Ecosystem / pain-point signal
- **GitHub** (optional PAT): trending repos (Search API proxy) + issues/discussions
  mining for pain points.
- **Libraries.io** (required key): rising/most-depended packages across ecosystems.

## Phase 6 — Launches
- **Product Hunt** (required token): today/this-week launches by topic. Note: no
  free-text post search; browse by topic/date.

## Phase 7 — The multiplier
- **Generic RSS/Atom fetcher** (no auth): ingest any feed → newsletters, dev
  blogs, freeCodeCamp, Techmeme. Emits feed-items (`score`/`num_comments` null).
  Biggest coverage gain per unit of code.

## Phase 8 — Output, not research
- **YouTube→blog wrapper** (Python, separate repo): async job pattern
  (`start_youtube_job(url)` → id; `check_job_status(id)`), wrapping the existing
  Tesseract OCR script. Most complex; do last.

## Phase 9 — Distribution (optional)
- Build `.mcpb` bundles for the servers worth one-click installing/sharing.

## Suggested next
Phase 0 (Hacker News pattern validation) → Phase 1 (credential + auth
infrastructure): build the shared foundation and prove the output contract
first, since every later source server copies that pattern.
