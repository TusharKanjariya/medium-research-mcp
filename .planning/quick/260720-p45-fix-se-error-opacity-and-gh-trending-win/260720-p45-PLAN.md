Verified facts (do not re-derive):

- getJson's terminal non-retryable-status path is shared/http_client.js lines 405-414 (`lastError = new Error(\`getJson: HTTP ${status} from ${redactUrl(url)}\`)`). The response body is UNCONSUMED at that point, so `response.text()` is available. Both the fixed-host and untrustedHost branches route through this same block — one edit covers all callers.
- **The trap:** that block sits inside the attempt loop's outer `try`. The test helper `res()` (test/http_client.test.js:10-19) has NO `.text()` method, so a bare `await response.text()` there throws a TypeError — which the outer `catch` classifies as `isNetwork` (retryable!), converting a terminal 4xx into a retried, stale-eligible fake network error and breaking existing 4xx tests. The body read MUST live in its own local try/catch that swallows everything.
- Discourse's `mapDiscourseError` and Mastodon's `mapMastodonError` match getJson errors by regex on the `HTTP 401`/`HTTP 422` substring (STATE.md decisions); http_client tests match `/503/`, `/HTTP 404/` etc. Appending a suffix after the existing message keeps every one green — the prefix must stay byte-identical.
- All SE tool handlers call `getJson(url, { cacheKey })` directly with seUrl-built URLs; there is no SE-side fetch wrapper. The chokepoint all SE tools share is therefore getJson itself — no stackexchange/server.js change is needed for fix 1.
- SE error bodies are compact JSON like `{"error_id":502,"error_name":"throttle_violation","error_message":"too many requests from this ip, will be blocked for 0.5 secs"}` — a 300-char snippet carries the whole thing verbatim.
- WR-01/CLAUDE.md: keys are never echoed in errors. `redactUrl` already strips the query string from the URL; the appended body is upstream-controlled text, so scrub any `key=…` token from the snippet before appending.
- `gh_trending_repos` builds its qualifiers inline (servers/github/server.js:217-233): `[query, language && \`language:${language}\`, \`pushed:>${cutoff}\`]` with `cutoff = new Date(Date.now() - SINCE_DAYS[since] * 864e5).toISOString().slice(0, 10)`. There is no injection seam in GH handlers; the repo convention for testable URL/qualifier construction is an exported pure helper (`seUrl`, `devtoTopUrl` precedents per STATE.md).
- registerTool takes RAW Zod shapes (NOT z.object()); inputSchema changes must be append-only.
- test/github.test.js:239-245 asserts the exact tool-name set; test/github.test.js:259-269 greps the server source for `fetch(`/`process.env` — neither is affected by these edits.
