## What Was Done

### Task 1 — getJson terminal-4xx body snippet (TDD)

- RED (5cf0a45): three tests — SE-style 400 JSON body must surface `throttle_violation`/`too many requests` on attempt 1; a `.text()`-less response must stay a first-attempt terminal error with no body suffix; a >1000-char body containing `key=SECRET123` must be bounded (<400-char message) and scrubbed.
- GREEN (c5f395e): the terminal non-retryable-status branch in `getJson` reads `response.text()` inside a **self-contained try/catch** (a read failure leaves the snippet empty — it never escapes to the outer catch where `err instanceof TypeError` would misclassify a terminal 4xx as retryable). - Scope guard honored: 5xx RetryableError path, success path, untrustedHost HTML gate, `postJson`, and `getText` untouched.
