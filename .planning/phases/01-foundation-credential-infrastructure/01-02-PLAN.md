## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP client → hn tool handler | Tool input (query, id, limit) crosses from host into the server |
| hn server → Algolia HN API | Outbound read-only requests to a public API; responses untrusted until schema-validated |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | query/id injected into Algolia URL | medium | mitigate | encodeURIComponent on query; Zod inputSchema validates types (numeric id/limit bounds) |
| T-02-02 | Tampering | unvalidated tool output reaching the medium-blog-pro skill | medium | mitigate | outputSchema = contract raw shape; SDK validates structuredContent on every return |
| T-02-03 | Denial of Service | hung Algolia upstream | low | mitigate | inherited from getJson: timeout + bounded retries + stale fallback |
</threat_model>
