<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP client → tool handler | Tool input crosses from the LLM/host into the server; validated by Zod inputSchema (later plans) |
| server → upstream HTTP API | Outbound requests to third-party public APIs; responses are untrusted until schema-validated |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Denial of Service | getJson against a hung upstream | medium | mitigate | AbortController timeout (timeoutMs) + bounded retries [500,1000,2000] + stale-cache fallback (§8) |
| T-01-02 | Tampering | non-JSON / malformed upstream body reaching callers | low | mitigate | res.json() wrapped in try/catch; parse failure treated as a failed attempt, not propagated raw (Pitfall 6) |
| T-01-03 | Information Disclosure | cache key inadvertently encoding a secret | low | mitigate | cacheKey derived from logical identity only; never include tokens (Pitfall 7) — enforced when authed callers arrive in later phases |
| T-01-SC | Tampering | npm installs (@modelcontextprotocol/sdk, zod) | high | accept | RESEARCH Package Legitimacy Audit: both Approved, no postinstall, ~40M/209M weekly downloads — no [ASSUMED]/[SUS] packages, so no blocking human checkpoint required |
</threat_model>
