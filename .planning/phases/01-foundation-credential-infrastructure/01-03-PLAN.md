<objective>
Build the credential and token-auth infrastructure every later source server copies: `credentials.js` as the single `process.env` reader with a logical-name→ENV_VAR map and per-service helper fragments (CRED-01, CRED-04); `auth.js` with one shared cached-token path serving both the optional Reddit OAuth2 password grant and the Lemmy login (CRED-02); and the documented `.env.example` + `.mcpb` `user_config` keychain pattern (CRED-03).

Purpose: Centralize all secret handling so no server ever reads `process.env` or hardcodes a secret, required credentials fail loudly while optional ones degrade to anonymous mode, and passwords are exchanged once for a cached token and never logged, persisted, or re-sent.
Output: `shared/credentials.js`, `shared/auth.js`, `.env.example`, `servers/hn/manifest.json`, and their `node:test` units.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator env / OS keychain → credentials.js | Secrets enter the process via env vars (dev .env or .mcpb-injected keychain values) |
| credentials.js → auth.js exchange | Passwords cross into auth.js only inside the exchange closure and the outgoing auth request body |
| auth.js → Reddit/Lemmy auth endpoints | Password sent once over TLS to obtain a token; thereafter only the token is used |
| repo → git | Only .env.example (no values) and manifest.json are committed; .env and real secrets never are |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Information Disclosure | credential read from a scattered process.env access | high | mitigate | credentials.js is the sole process.env reader; ENV_VAR is the single source of truth (CLAUDE.md, CRED-01) |
| T-03-02 | Information Disclosure | password logged, persisted, or re-sent per request | high | mitigate | password confined to the exchange closure + request body; token-only cache; error messages name status not value; test asserts password absent from cache (CRED-02) |
| T-03-03 | Information Disclosure | secret persisted plaintext in a bundle | high | mitigate | .mcpb user_config "sensitive": true → OS keychain; ${user_config.*} injected at spawn, never on disk (CRED-03) |
| T-03-04 | Information Disclosure | .env committed to git | high | mitigate | .gitignore excludes .env; only .env.example (names + comments, no values) is committed |
| T-03-05 | Spoofing | required credential silently missing → wrong-auth calls | medium | mitigate | requireCred throws a clear "set X" error for Libraries.io / Product Hunt; optional sources degrade to anonymous (CRED-04) |
| T-03-SC | Tampering | npm installs for this phase | high | accept | No new packages introduced in this plan (auth uses Node built-ins: Buffer, fetch, URLSearchParams); phase-level audit clean in RESEARCH |
</threat_model>
