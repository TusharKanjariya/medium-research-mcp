## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator → public npm registry | the published tarball is world-installable; a wrong name or a leaked file is permanent |
| local repo → public GitHub | the visibility flip makes all git history world-readable |
| published package → consumer machine | a lifecycle script would execute on a consumer's install |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-03 | Tampering/Elevation | consumer npm/npx install | low | mitigate | package.json has zero lifecycle scripts; the checklist includes a `--ignore-scripts` install verify (a no-op that still starts the bins) |
| T-10-04 | Spoofing | npm name `medium-research-mcp` | medium | mitigate | Re-confirm `npm view medium-research-mcp version` returns not-found immediately before publish (A2); abort if claimed rather than scope/rename (D-03) |
| T-10-05 | Information Disclosure | npm publish tarball | high | mitigate | Final `npm pack --dry-run` inspection inside the publish checkpoint before `npm publish`; publish blocks on any unexpected file |
| T-10-06 | Information Disclosure | public GitHub history | high | mitigate | The visibility flip is gated on the 10-01 secret-scan PASS; a FAIL blocks the flip (Task 3 precondition) |
| T-10-07 | Tampering | publish/flip from a dirty or stale tree | low | mitigate | Publish only from a clean tree; `git push origin master` (31 commits) before the github live-verify (Pitfall 1) |
</threat_model>
