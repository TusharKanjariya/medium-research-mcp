<objective>
Introduce the project's FIRST runtime dependency beyond `@modelcontextprotocol/sdk`
+ `zod` — `fast-xml-parser`, pinned to `^4.5.7` (the `legacy` dist-tag, NOT `^5`) —
behind a blocking human supply-chain checkpoint (D-08). The RSS server (04-03) needs
a robust XML parser (CDATA/namespaces/entities/both dialects) that is error-prone to
hand-roll; `fast-xml-parser@4` carries a single zero-dep transitive (`strnum@1`),
whereas `^5` exploded into 6+ new low-download sub-packages the project explicitly
does not want.

Purpose: Add the parser safely, with the operator confirming the resolved tree before
it is trusted. This is a small, isolated plan on purpose — a blocking checkpoint must
not be buried inside implementation work.
Output: `fast-xml-parser@^4.5.7` in package.json + a committed lockfile recording the
`fast-xml-parser@4.x → strnum@1.x` tree. No code — the parser is consumed in 04-03.
</objective>
