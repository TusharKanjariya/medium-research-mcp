<objective>
Prove the project's thesis (OUT-02): a single research run pulls from 5+ shipped
sources and returns one uniform list the consumer ranks and filters with ZERO
per-source branches. Add `mergeRank` to `shared/rank.js` (D-09) — a flat merge over
`results[]` plus one nulls-last score-descending comparator, reading only contract
fields — then assert it against recorded fixtures from 5+ sources in
`test/uniform-run.test.js` (offline CI, D-09/D-10), and ship a runnable live demo in
`examples/uniform-run.mjs` (manual smoke, not a CI gate, D-10).

Because every server already emits the same item shape, the merge is a concat and the
rank is one comparator — no source-specific code exists anywhere in the path. Shipping
`mergeRank` as shared infra (not test-local) makes the proof assert the REAL code path
the consumer runs and gives the consumer a reference implementation.

Purpose: Turn "the contract enables a branch-free multi-source merge" from a claim into
an executable assertion across HN + Stack Exchange + Lobsters + Dev.to + GitHub + RSS.
Output: `shared/rank.js` (mergeRank + a filter example), test/uniform-run.test.js,
examples/uniform-run.mjs.
</objective>
