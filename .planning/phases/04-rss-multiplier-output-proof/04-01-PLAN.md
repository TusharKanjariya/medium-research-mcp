<objective>
Add the shared, SSRF-hardened text-fetch path that the RSS server (04-03) will
build on: a `getText(url, opts)` sibling of `getJson` in `shared/http_client.js`
(D-07), an `assertSafeUrl` guard enforcing the SSRF controls (D-01/D-02), and the
optional `RSS_ALLOWED_HOSTS` operator allowlist in `shared/credentials.js` (D-03).

This is the project's FIRST fetch path whose outbound host comes from untrusted
tool input, so the security controls live on the single shared chokepoint (not in
the server) where they cannot be bypassed and any future text source inherits them.

Purpose: Make arbitrary-URL feed fetching safe and resilient before any server can
call it. The RSS server stays pure field-mapping because all HTTP + SSRF logic is here.
Output: `getText`, `assertSafeUrl` (both exported), `rssAllowedHosts()`, extended
credential + http_client unit tests. No parsing, no server — those are 04-03.
</objective>

    `addAddress`: IPv4 `0.0.0.0/8`, `10.0.0.0/8`, `100.64.0.0/10` (CGNAT),
    `127.0.0.0/8`, `169.254.0.0/16` (link-local incl. `169.254.169.254` metadata),

    Define `ALLOWED_SCHEMES = new Set(["http:","https:"])`.
    Export `async function assertSafeUrl(rawUrl, { lookup = dnsLookup } = {})` that:
    (1) WHATWG-parses the URL, throwing a clear `rss: invalid URL` on failure;
    (2) rejects any protocol not in ALLOWED_SCHEMES with a clear message naming the
    scheme (D-01); (3) if `rssAllowedHosts()` returns a Set, rejects a host not in it
    naming RSS_ALLOWED_HOSTS (D-03); (4) resolves `lookup(hostname, { all: true })`
    and, for EVERY returned address, canonicalizes an `::ffff:` IPv4-mapped IPv6 prefix
    off before classifying with `isIP` and checking `DENY.check(ip, fam)` — throwing
    `rss: host <h> resolves to a blocked address` if ANY resolved IP is blocked (D-02).
    Return the parsed URL on success. `lookup` is injectable so tests force a host to
    "resolve" to a private IP without real DNS. Use `redactUrl` in error text (V7).
    Extend test/http_client.test.js with assertSafeUrl cases: rejects `file://…`,
    `ftp://…`, `data:…`; rejects `http://127.0.0.1`, `http://169.254.169.254`,
    `http://[::1]`, and a public hostname whose injected `lookup` returns `10.0.0.5`;
    accepts a public host whose injected `lookup` returns a public IP; with
    RSS_ALLOWED_HOSTS set (via process.env in-test) accepts only a listed host and
    rejects an unlisted one; canonicalizes `::ffff:169.254.169.254` → blocked.
  </action>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tool input → getText | Untrusted `url` (and any redirect Location) chooses the outbound host — the defining new attack surface of this phase. |
| getText → credentials.js | Only `rssAllowedHosts()`/`userAgent()` cross; no secret and no process.env read leaves credentials.js. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Information Disclosure | getText → cloud metadata (`169.254.169.254`) | high | mitigate | BlockList link-local `169.254.0.0/16` + resolve-and-classify every IP in assertSafeUrl (D-02). |
| T-04-02 | Information Disclosure / Elevation | getText → loopback/RFC1918 internal scan | high | mitigate | BlockList `127.0.0.0/8`,`10/8`,`172.16/12`,`192.168/16`,`100.64/10`,`::1`,`fc00::/7` (D-02). |
| T-04-03 | Tampering / Info Disclosure | `file:`/`gopher:`/`data:` scheme abuse | high | mitigate | Scheme allowlist http/https only (D-01). |
| T-04-04 | Information Disclosure | Public feed 302 → `http://169.254.169.254/…` (redirect-to-internal) | high | mitigate | `redirect:"manual"` + assertSafeUrl re-validation on every hop (D-02). |
| T-04-05 | Information Disclosure | IPv4-mapped IPv6 / alternate IP encoding bypass | medium | mitigate | Canonicalize `::ffff:` prefix + `net.isIP`/BlockList (never string-compare). |
| T-04-06 | Information Disclosure | DNS rebinding (public→internal between validate and connect, TOCTOU) | low | accept | Documented residual for a local single-user tool (RESEARCH A1); optional undici custom-lookup dispatcher noted as future hardening, not built. |
| T-04-07 | Denial of Service | Huge/slow body from an arbitrary host | medium | mitigate | Existing 10s per-attempt timeout inherited; item-count cap enforced by rss_fetch in 04-03. |
| T-04-08 | Information Disclosure | Credential/host leak in error text | low | mitigate | Reuse `redactUrl` (origin+path only) in all getText/assertSafeUrl errors (V7). |
</threat_model>
