<objective>
Deliver the two required-credential source servers: Libraries.io (SRC-07 — most-depended
packages, `dependents_count`->score) over REST `getJson()`, and Product Hunt (SRC-08 —
today/this-week launches, votes->score, comments->num_comments) over GraphQL `postJson()`.
Both prove the phase's core obligation (criterion 4): a missing required credential fails
loudly with a clear "set X" error, verified by a unit test.

Purpose: exercise the required-credential path end to end (contrast with GitHub's optional
PAT) and surface package-ecosystem momentum + launch signal for blog topics.
Output: two servers + manifests + two test files + fixtures.

Note: this plan depends on 03-01 (the shared TYPE enum extension) — it emits `type:"package"`
and `type:"launch"`, which only validate once 03-01 Task 1 has landed. It does NOT edit
shared/contract.js; the wave-2 ordering guarantees no concurrent contract.js edit.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Claude Desktop tool input -> server handler | Untrusted query/platform/sort/topic/period/id cross here |
| server -> libraries.io / api.producthunt.com | Outbound requests to FIXED module-constant hosts |
| LIBRARIESIO_KEY (query param) / PRODUCTHUNT_TOKEN (header) -> request | Required credentials enter via librariesIoParams()/productHuntHeaders() only |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-04 | Information Disclosure | Libraries.io api_key (query param) | high | mitigate | libUrl mirrors seUrl: authed URL carries api_key, cacheKey is secret-free; redactUrl strips the query from error text; unit test asserts api_key never in cacheKey (Pitfall 3, WR-01) |
| T-03-05 | Elevation/Repudiation | required-cred bypass (unauth API call) | medium | mitigate | librariesIoParams()/productHuntHeaders() throw before any request when the env var is unset; unit-tested throw (criterion 4, D-10) |
| T-03-06 | Tampering/Info Disclosure (SSRF) | outbound host selection | medium | mitigate | LIB and PH_GRAPHQL are module constants; platform/topic/sort are query/GraphQL VALUES sent to the fixed host (validated upstream), never host selectors; path segments encodeURIComponent-encoded |
| T-03-07 | Correctness/DoS-ish | GraphQL 200-with-errors treated as success | low | mitigate | Explicit raw.errors check throws a clear error before reading raw.data (Pitfall 4); unit-tested |
| T-03-SC | Tampering | npm installs | low | accept | No package installs this phase (RESEARCH Package Legitimacy Audit — zero new deps); no supply-chain surface to gate |
</threat_model>
