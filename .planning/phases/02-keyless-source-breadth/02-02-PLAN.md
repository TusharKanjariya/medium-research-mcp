<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Claude Desktop -> server (tool input) | `query`, `id`, `tag`, `sort`, `limit` untrusted; zod-validated + encoded before the URL |
| server -> lobste.rs / lemmy instance (HTTPS) | outbound via getJson; user input only ever populates query params/path segments against a fixed or operator-set host |
| operator env -> LEMMY_INSTANCE / LEMMY_USERNAME / LEMMY_PASSWORD | read only via credentials.js/auth.js |
| server -> lemmyJwt() | password exchanged once for an in-memory-cached jwt (auth.js) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-02-URL | Tampering | Lobsters `tag`/`id`, Lemmy `id`/`community` path/query | medium | mitigate | `encodeURIComponent` on path segments; `URLSearchParams` for query values; fixed host for Lobsters (Pitfall 8) |
| T-02-02-SSRF | Tampering/Info-disclosure | `LEMMY_INSTANCE` override selecting the outbound host | high | mitigate | instance base URL comes ONLY from operator-set env via `lemmyInstance()`; it is NOT exposed as a per-call tool parameter, so untrusted tool input can never select an arbitrary host; documented as trusted full-HTTPS-URL operator config |
| T-02-02-CRED | Info disclosure | LEMMY_PASSWORD / jwt | high | mitigate | password read only via `lemmyCreds()`, exchanged in-memory by `auth.js`, never logged/persisted/sent per-request; jwt cached in-memory only, never echoed in tool output or errors; `sensitive: true` in manifest |
| T-02-02-AUTHFAIL | DoS/availability | missing/invalid Lemmy creds | low | accept | `lemmyJwt()` returns null when creds absent => anonymous reads, no hard error (D-06); a failed exchange writes no cache entry |
| T-02-02-DOS | DoS | unbounded `limit`/window | low | mitigate | `limit` bounded `.min(1).max(50)`; client-side search window bounded; 10s timeout + cache from getJson |
| T-02-02-SC | Tampering | npm/pip/cargo installs | n/a | accept | No packages installed this phase (RESEARCH Package Legitimacy Audit) |

Both `high` threats (SSRF via instance override, credential/jwt leak) are mitigated at ASVS L1; none remain unmitigated at/above the `high` block threshold.
</threat_model>
