<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Claude Desktop -> server (tool input) | `query`, `id`, `tag`, `limit` untrusted; zod-validated; Hashnode routes via GraphQL variables, Dev.to via encoded query/path |
| server -> gql.hashnode.com (HTTPS POST) | outbound via postJson; user input only ever enters GraphQL `variables`, never the query body |
| server -> dev.to/api (HTTPS GET) | outbound via getJson; user input only ever populates query params/path segments against the fixed Forem host |
| response body -> normalizeItem/stripHtml | untrusted response HTML stripped centrally; never evaluated |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-03-GQL | Tampering | Hashnode GraphQL query construction | high | mitigate | user input passed exclusively via GraphQL `variables`; query strings are fixed module constants — never string-interpolated with tool input (Security V5 / anti-pattern) |
| T-02-03-URL | Tampering | Dev.to `tag`/`id` path/query | medium | mitigate | `encodeURIComponent` on path segments; `tag`/query as encoded params against the fixed `dev.to/api` host (Pitfall 8) |
| T-02-03-HTML | Tampering (untrusted response) | article/comment body HTML | low | mitigate | HTML stripped via shared `stripHtml`/`normalizeItem`; response content is never eval'd |
| T-02-03-CACHE | Info disclosure | postJson cache key | low | mitigate | cache key is `url+sha1(body)`, a logical non-secret key; Hashnode is keyless so no secret ever enters the key (invariant kept) |
| T-02-03-DOS | DoS | unbounded `per_page`/window/`first` | low | mitigate | `limit`/window bounded `.min(1).max(50)`; 10s timeout + cache from the shared client |
| T-02-03-SC | Tampering | npm/pip/cargo installs | n/a | accept | No packages installed this phase; `node:crypto` for postJson hashing is a Node built-in (RESEARCH Package Legitimacy Audit) |

The `high` threat (GraphQL injection) is mitigated via variables at ASVS L1; none remain unmitigated at/above the `high` block threshold.
</threat_model>
