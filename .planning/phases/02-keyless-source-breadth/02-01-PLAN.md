<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Claude Desktop -> server (tool input) | `site`, `query`, `id`, `sort`, `limit` are untrusted; validated by zod, encoded before entering the URL |
| server -> api.stackexchange.com (HTTPS) | outbound fetch via getJson; only ever query params against the fixed SE host |
| operator env -> STACKEXCHANGE_KEY | optional secret read only via credentials.js |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01-URL | Tampering | so_get_question `id` path segment / `site`/`query` params | medium | mitigate | `encodeURIComponent(id)`; `site`/`q` carried as `URLSearchParams` values against the fixed `api.stackexchange.com` host — user input never selects the host (Pitfall 8) |
| T-02-01-SITE | Tampering (SSRF-shaped) | `site` free passthrough (D-03) | low | accept | `site` only populates the `site=` query param on the fixed SE base URL; it cannot redirect to another host. SE validates the value and errors on unknown sites — no local whitelist by design |
| T-02-01-KEY | Info disclosure | STACKEXCHANGE_KEY | medium | mitigate | read only via `stackExchangeParams()`; used as a query fragment only when present; never logged, never echoed in tool output or errors; `sensitive: true` in manifest (keychain) |
| T-02-01-DOS | DoS | unbounded `pagesize` | low | mitigate | `limit` bounded `.min(1).max(50)`; 10s timeout + 15-min cache inherited from getJson |
| T-02-01-SC | Tampering | npm/pip/cargo installs | n/a | accept | No packages installed this phase — SE reuses `@modelcontextprotocol/sdk` + `zod` already vetted in Phase 1 (RESEARCH Package Legitimacy Audit) |

All realistic threats are mitigated or accepted with rationale at ASVS L1; none remain unmitigated at/above `high`.
</threat_model>
