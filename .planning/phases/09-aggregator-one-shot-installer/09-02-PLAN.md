## process.env boundary (read before coding)

CLAUDE.md forbids reading `process.env` outside `shared/credentials.js` — that rule is about **secrets in servers**. The installer is a CLI and needs OS config-path discovery; reading `process.env.APPDATA` / `process.env.LOCALAPPDATA` for the Windows Claude Desktop path (with `path.join(os.homedir(), "AppData", "Roaming")` as a fallback) is path discovery, NOT a credential read, and is permitted here. Keys still flow ONLY through interactive prompts into the client config's `env`/`environment` block — the installer never reads a key from `process.env` and never hardcodes one. Use `os.homedir()` for all `~`-based paths.
</constraints_callout>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| installer CLI ↔ user's client config files | the ONLY new outbound file-write surface — installer reads and rewrites Claude/Cursor/Codex/OpenCode configs on the user's machine |
| interactive prompt ↔ secret keys | user-pasted API tokens flow through readline into a plaintext config `env`/`environment` block |
| CLI argv ↔ installer | `--client`/`--separate`/`--yes` flags are untrusted input |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09B-01 | Tampering | config corruption / loss of unrelated server entries during merge | high | mitigate | backup-first (timestamped copyFileSync) + parse-or-abort + set-only-our-keys JSON merge + remove-then-append-only-our-tables TOML splice; tests assert an unrelated entry/table survives. |
| T-09B-02 | Tampering | secret containing `"`/`\`/newline breaking JSON/TOML syntax | high | mitigate | JSON safe via `JSON.stringify`; TOML via `escapeTomlString` (escape `\`/`"`, reject control chars). Test with a quote-bearing key. |
| T-09B-03 | Information Disclosure | API key written plaintext to on-disk config | medium | accept | D-05 accepted trade-off for the all-at-once goal; installer prints a one-line plaintext-vs-`.mcpb`-keychain warning. No encryption (keychain path is the deferred `.mcpb` bundle). |
| T-09B-04 | Elevation of Privilege / Input Validation | malicious/typo `--client` or unknown flag steering a write | medium | mitigate | validate `--client` against the 4-value allowlist; reject unknown flags; write only to detected config paths, never a caller-supplied path. |
| T-09B-05 | Denial of Service | prompt hang in a non-TTY/CI context | low | mitigate | guard on `!process.stdin.isTTY` → require `--client`/`--yes`, never block on a prompt (research Pitfall 7). |
| T-09B-SC | Tampering | supply-chain / new dependency | low | accept | Installs ZERO packages — `node:readline/promises`/`fs`/`path`/`os` + no parser/prompt lib. A new `dependencies` entry is a scope violation, rejected at review. |
