<objective>
Build the `medium-research-all` aggregator (AGG-01, D-01, D-02): one MCP process that exposes the full union of all 11 sources' 37 tools, with tool names and the output contract unchanged, the 11 standalone bins and `.mcpb` bundles untouched, and zero new runtime dependencies.

The merge seam is a mechanical refactor (from 09-RESEARCH §Aggregator Merge Seam): each server wraps its existing `server.registerTool(...)` calls in an exported `registerTools(server)` function and calls it once locally; the aggregator imports all 11 functions and calls each against a single `McpServer`. Public SDK API only — the SDK exposes no merge/mount primitive, and reaching into the private `_registeredTools` map was rejected as a 3am liability (research §Alternatives).

Purpose: satisfy success criteria 1 (one config entry → every source's tools, identical names + contract) and 5 (11 bins + `.mcpb` unchanged, full suite passes).
Output: `servers/aggregator/server.js`, the `registerTools` seam in all 11 servers, `test/aggregator.test.js`, and the `medium-research-all` bin.
</objective>
