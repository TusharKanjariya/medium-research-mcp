<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `.mcpb` user_config → OS keychain → server env | A user_config field marked `sensitive:true` is stored in the OS keychain and injected as env at spawn; a field NOT marked sensitive is written to host config in plaintext |
| manifest env declaration → server credential read | The manifest promises which secrets a server needs; a mismatch either leaks an unused secret ref or starves a needed one |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-03 | Information disclosure | credentialed user_config fields | high | mitigate | Every secret field keeps `"sensitive": true` (keychain, masked, never plaintext on disk); asserted per credentialed manifest by the D-05 test + a live keychain smoke in plan 03 (D-04) |
| T-08-07 | Information disclosure | hn over-declared env refs | medium | mitigate | Remove reddit_client_secret + librariesio_key from hn (it reads neither) so no unused secret ref is presented to the user; D-05 test enforces manifest env ⇒ imported-by-server |
| T-08-SC | Tampering | ENV_VAR single-source drift | low | accept | Test reads ENV names from credentials.js source (no second copy to drift); the frozen credentials module is unchanged this phase |
</threat_model>
