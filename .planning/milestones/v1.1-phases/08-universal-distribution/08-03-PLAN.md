producthunt (D-01, no partial/defer) — from a single staging script (PKG-01, part B,

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| lockfile → vendored node_modules in bundle | Whatever `npm ci` installs (and any postinstall it runs) is what ships inside every `.mcpb` |
| `.mcpb` bundle → Claude Desktop spawn | The bundled server runs on the user's machine with the injected user_config secrets |
| build stage temp dir → `dist/` artifact | Anything left in the stage (test/, .env) would be packed unless excluded |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-04 | Tampering | vendored production node_modules | high | mitigate | `npm ci --omit=dev --ignore-scripts` from the pinned lockfile — deterministic deps, no dev deps, and NO dependency postinstall script runs into a bundle; size band assertion flags a leaked dev-dep bloat |
| T-08-05 | Information disclosure | bundle contents | high | mitigate | `.mcpbignore` excludes test/, *.md, .planning/, .env; secrets are user_config→keychain (never packed); Option-A stage copies only manifest + node_modules + shared/ + the one server.js |
| T-08-08 | Denial of service | broken bundle shipped | medium | mitigate | Every stage is gated by `mcpb validate` + a real MCP-initialize spawn test BEFORE pack; a stage that can't resolve ../../shared fails the spawn test and aborts (never emits a broken .mcpb) |
| T-08-SC | Tampering | `@anthropic-ai/mcpb` pack tool | high | mitigate | Invoked from the pinned local devDependency (2.1.2, verified Anthropic maintainers), never a global or npx-latest; it never enters a runtime/bundle dep tree |
</threat_model>
