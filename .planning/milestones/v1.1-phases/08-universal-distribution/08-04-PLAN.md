## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| docs → user's client config file | The snippets the user copies decide whether secrets land in plaintext client config vs the keychain |
| example script → live third-party APIs | The sweep fetches user-host instances (Discourse/Mastodon) over the guarded getJson path |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-09 | Information disclosure | plaintext env blocks in client config | medium | mitigate | Docs steer users to the `.mcpb` keychain path for Claude Desktop and clearly mark client `env` blocks as plaintext-on-disk; secrets are never printed in examples (placeholder values only) |
| T-08-10 | Spoofing / SSRF | example fetches user-host instances | low | accept | The example calls `getJson(..., { untrustedHost: true })` — the frozen SSRF guard (SEC-01) applies unchanged; instances are public example constants, not tool input |
| T-08-SC | Tampering | example reuses server helpers | low | accept | Imports only existing exported helpers + shared modules; adds no new dependency and no new network/merge logic |
</threat_model>
