Deliver the SEC-02 parameterization audit (D-16): a committed static test that fails on any hardcoded account/instance/feed anywhere in the suite. This is the enforcement that guarantees "no hardcoded targets — targets are tool parameters" holds now and stays true as servers are added.

The test scans `servers/*/server.js` (plus the rss `resolve*` helpers) for `http(s)://` host literals and `@handle` literals and asserts each host is an allowlisted fixed platform base (or an allowlisted suffix).
