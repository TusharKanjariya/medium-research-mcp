<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP caller → discourse_* `instance` param | Untrusted host string selects the outbound base |
| Discourse instance → server | Response may be an HTML login/interstitial page (200) or a 4xx lockdown |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Information disclosure (SSRF) | discourse_* getJson with user-supplied `instance` (e.g. 127.0.0.1 / 169.254.169.254) | high | mitigate | `getJson(url,{untrustedHost:true})` on every call (assertSafeUrl denylist + per-hop redirect re-validation); private-IP reject test (Task 3) |
| T-07-04 | Denial of service | HTML login page parsed as JSON → crash | medium | mitigate | Phase 5 content-type gate fails closed on text/html 200; D-11 catch maps it to a readable error (Task 1); HTML-200 fixture test (Task 3) |
| T-07-02 | Tampering | Hardcoded forum host/account creeps into discourse server.js | medium | mitigate | Base is always the tool param (no host literal); enforced by the plan 07-04 SEC-02 audit |
| T-07-SC | Tampering | package installs | low | accept | Zero new dependencies (RESEARCH §Standard Stack) — no install surface |
| T-04-06 | Information disclosure | DNS-rebinding TOCTOU on guarded path | low | accept | Accepted residual (SEC-03) for a local single-user tool; not reopened |
</threat_model>
