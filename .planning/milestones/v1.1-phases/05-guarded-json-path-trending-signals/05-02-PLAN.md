<objective>
Add an `hn_rising` tool to the Hacker News server that approximates HN's rising/front-
page climbers using Algolia `search_by_date` + `numericFilters` (Algolia has no rising
endpoint), then re-sorts server-side by points/hour velocity so genuine fast-climbers
surface first (TREND-03, D-11). Fixed-host, keyless JSON GET through the shared client;
pure field-map + URL-construction over the frozen contract.

Purpose: give agents a "what's climbing on HN" signal without inventing new item fields
(velocity is ordering only) and without silently reordering merged mergeRank output
(Pitfall 3 — never return raw date order).
Output: the hn_rising tool, two exported pure helpers, and deterministic offline tests.
</objective>
