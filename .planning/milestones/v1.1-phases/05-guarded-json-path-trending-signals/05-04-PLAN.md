<objective>
Extend the existing `devto_top` tool (do NOT add a 5th tool, D-14) with an explicit
`mode` enum (top | rising), a `days` window (used only in top mode), and an optional
`tag`, so agents get Dev.to's top-of-window AND rising articles combinable with a tag
(TREND-01, D-15). Because `registerTool` takes a raw field shape, cross-field validation
(reject `rising` + `days`) is impossible in Zod (Pitfall 4) — the forbidden-combo guard
lives in an exported pure `devtoTopUrl` helper that throws before any fetch.

Purpose: cover both Dev.to trending signals through one well-documented tool over the
frozen contract, with unambiguous integer-days semantics and explicit mode.
Output: the extended devto_top, the devtoTopUrl helper, and offline tests.
</objective>
